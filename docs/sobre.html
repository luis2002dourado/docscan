Sobre

O DocScan é uma ferramenta web para quem precisa fotografar um papel, juntar PDFs ou girar páginas sem criar conta.

O código está no GitHub. A origem do projeto é o Maranhão, Brasil. Não há loja física nem CNPJ publicado nesta página.

Promessa de resposta: issues no GitHub, melhor esforço em até 2 dias úteis.
