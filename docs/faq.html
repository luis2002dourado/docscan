FAQ

1. Meu documento vai para a nuvem?

Não para um servidor nosso. O processamento é no navegador. CDNs só entregam as bibliotecas. A hospedagem GitHub serve o site estático.

2. Quais arquivos posso usar?

Imagens JPEG, PNG e WebP na digitalização; PDF para juntar e editar. Até 25 MB por arquivo.

3. O OCR é perfeito?

Não. É o Tesseract no seu aparelho (português e inglês). Revise o texto, principalmente em fotos ruins.

4. O recorte automático sempre acha a folha?

Não. Em fundo confuso use o modo “Só realce” ou “Original”.

5. Como falo com vocês?

Pelo GitHub Issues. Promessa: melhor esforço em até 2 dias úteis, sem 24h.
