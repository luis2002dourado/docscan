# DocScan v23

Contornos interrompidos podem ser reconstruídos pelo envoltório convexo, mas apenas com suporte forte nas quatro bordas e contraste externo em pelo menos três lados. A busca inclui os canais RGB separadamente. Os contornos originais continuam sendo avaliados.

Impressão de fotos: A4 retrato com margens de 10 mm, uma imagem por página, centralizada e dimensionada proporcionalmente com object-fit: contain. A impressão aguarda a decodificação das imagens.

Validação: imagem privada enviada pelo usuário passou de não detectada para documento completo detectado. Resultado visual inspecionado; imagem privada e resultado não foram incluídos no repositório. Teste de impressão gerou uma página A4 tanto para documento horizontal quanto vertical. Testes anteriores mantidos.

A geometria da impressão foi verificada no Chromium, sem impressora física. O diálogo de impressão do sistema pode permitir que o usuário substitua papel e escala.
